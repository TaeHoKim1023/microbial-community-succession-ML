## Overview

This repository contains all analysis code used to predict the freshness stage and total plate count (TPC) of broiler chicken from 16S rRNA amplicon sequencing data (genus-level CLR-transformed microbiome profiles).
The pipeline implements a two-stage approach: **(1) freshness stage classification → (2) TPC regression**, with systematic controls for data leakage and label sensitivity.

### Freshness Stage Definition

Labels are defined on a continuous TPC (log CFU/g) scale using threshold-based assignment:

| Label                  | TPC (log CFU/g)                      | Code value |
| ---------------------- | ------------------------------------ | ---------- |
| **Early**        | < threshold_low                      | 0          |
| **Intermediate** | threshold_low ≤ · < threshold_high | 2          |
| **Late**         | ≥ threshold_high                    | 1          |

Thresholds are optimized independently on each seed's training data using Optuna (TPE sampler) or K-means clustering. The threshold derived from seed-42 is selected as the representative value (inter-seed std ≤ 0.06 log CFU/g) and applied uniformly across all 10 seeds to ensure biologically consistent label assignment.

Notebooks must be run in the order below. Each notebook saves its outputs as `.pkl` files consumed by the next stage. Intermediate `.pkl` files are provided so any notebook can be run independently.

1. preprocessing.ipynb ↓ genus_preprocessed.pkl, splits.pkl

## Analysis Design

### 4 Conditions

All downstream analyses (classification and regression) are evaluated under four combinations of labeling method and feature selection method:

| Condition | Labeling threshold | Feature selection                         |
| --------- | ------------------ | ----------------------------------------- |
| Cond 1    | Optuna (TPE)       | Fold-change Top 10                        |
| Cond 2    | Optuna (TPE)       | Day-ANOVA (q < 0.05) → PLS-DA VIP ≥ 1.0 |
| Cond 3    | K-means            | Fold-change Top 10                        |
| Cond 4    | K-means            | Day-ANOVA (q < 0.05) → PLS-DA VIP ≥ 1.0 |

Feature selection is performed on **training data only** in each seed to prevent data leakage.

### Seed Strategy

- **label_seed**: Controls Optuna/K-means threshold optimization. Thresholds are fit independently for all 10 label seeds (38–47); the seed-42 threshold is selected as representative (inter-seed std ≤ 0.06 log CFU/g) and applied uniformly to all train/test/val splits.
- **train_seed**: Controls stratified 70/20/10 train/test/val splits. 10 seeds (38–47) used for all performance reporting (mean ± SD).
- **Sensitivity analysis**: 10 label seeds × 10 train seeds = 100 combinations tested in `4. classification.ipynb` and `5. regression.ipynb`.

### Leakage Controls

1. **Label generation**: TPC-only criterion; threshold optimization performed on training data only; seed-42 threshold applied uniformly to prevent label inconsistency across splits.
2. **Feature selection**: FC Top10 and VIP computed from training data only in each seed.
3. **Permutation test** (`7. leakage_test.ipynb`): Two-test design — (i) fixed-feature permutation to confirm model performance exceeds chance, (ii) full-pipeline permutation (feature re-selection per fold per permutation) to confirm feature selection itself does not introduce leakage. Both tests share the same 1,000-permutation sequence (rng seed = 42).

## Reproducibility Notes

- All random operations use explicit `random_state` / `numpy.random.default_rng(42)` where applicable.
- Model internal random states are fixed at 42 across all train seeds; this isolates data-partitioning variability as the sole source of performance variance across the 10 seeds.
- `labeled_splits.pkl` and `kmeans_labeled_splits.pkl` store the exact train/test/val indices for each seed; re-loading these files guarantees identical splits across environments.
- The permutation test in `7. leakage_test.ipynb` uses a fixed `rng = np.random.default_rng(42)` shared between Test 1 and Test 2, enabling direct null-distribution comparison.
- SHAP values in `4. classification.ipynb` and `5. regression.ipynb` are computed on seed-42 test sets using the stored best model pipeline; results are deterministic given the fixed seed.
- LSTM results may vary slightly across hardware environments due to floating-point non-determinism. All reported values are fixed to the stored `regression_results.pkl` output.
